2. Homepage — /

Σελίδες → Home → box “Homepage”

Do not write the page in the empty block editor. Scroll to the Homepage fields and edit there.

Once: Settings → Reading → static homepage = Home.

9. Publish checklist

  1. Open the right item from the quick map.
  2. Edit the ACF box fields (not the empty Gutenberg area).
  3. Click Αποθήκευση / Update.
  4. Check the matching public URL (hard-refresh if needed).
  5. Keep slugs stable: Home (front page), about, contact.

Images

  • Prefer wide JPG/WebP for heroes (~1600px+).
  • Use each field’s Add Image, or Media Library.
  • Fill Alt text. Empty hero → site uses a fallback photo.
